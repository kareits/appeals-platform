# CLAUDE.md — обязательные правила

## Перед началом

1. Прочитай `docs/00_MASTER_SPEC.md`.
2. Прочитай ТЗ текущей фазы.
3. Прочитай спецификации только затрагиваемых сервисов.
4. Сформулируй краткий план.
5. Перечисли предполагаемые изменяемые файлы.

## Архитектурные запреты

- Не обращаться к БД другого сервиса.
- Не импортировать код одного сервиса из другого.
- Не хранить бинарные файлы в RabbitMQ.
- Не хранить PDF, изображения и полные письма в Flowable variables.
- Не давать frontend прямой доступ к Flowable и файловой системе.
- Не добавлять инфраструктуру без ADR.
- Не помещать бизнес-логику в FastAPI route handlers.
- Не делать необратимые миграции без плана.
- Не удалять регуляторные данные обычным пользовательским действием.
- Не давать AI-сервисам прямой доступ к Exchange и прикладным БД.

## Владение данными

- Ticket Service: карточка, классификация, решение, аналитика.
- Flowable: процесс, задачи, назначения, таймеры, согласования.
- Mailbox Service: входящие/исходящие письма.
- Document Service: файлы, версии, хеши, скачивания.
- IAM Service: пользователи, роли, команды.
- Notification Service: уведомления.
- Integration Service: адаптация внутренних систем.

## Контракты

Сначала меняй OpenAPI/JSON Schema и контрактные тесты, затем реализацию. События должны иметь `eventId`, `eventType`, `eventVersion`, `occurredAt`, `producer`, `correlationId`, `causationId`, `payload`. Consumers идемпотентны. Для публикации используется Transactional Outbox.

## Код

- Python 3.12+;
- FastAPI, Pydantic v2, SQLAlchemy 2, Alembic;
- HTTPX, aio-pika;
- Ruff, Pyright/mypy;
- pytest, pytest-asyncio;
- UTC в хранилищах;
- UUIDv7/ULID для внутренних ID;
- бизнес-номер обращения отдельно;
- строгая типизация.

## Definition of Done

- acceptance criteria выполнены;
- тесты добавлены и проходят;
- миграции проверены;
- OpenAPI/события актуальны;
- документация обновлена;
- отсутствуют межсервисные DB-зависимости;
- выполнена проверка безопасности.

## Неопределенные внешние интеграции

Создавай интерфейс, mock/fake и документируй допущение. Не придумывай реальные credentials или endpoint.

## AI

AI-результат хранится отдельно от подтвержденных данных. AI может распознавать, классифицировать, извлекать и формировать черновики. AI не может самостоятельно принимать решение по реструктуризации, менять договор, закрывать тикет, выбирать произвольного получателя или отправлять юридически значимый отказ.
