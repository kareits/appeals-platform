# Solva Appeals Platform — комплект ТЗ для Claude

## Назначение

Комплект предназначен для поэтапной разработки внутренней платформы регистрации, обработки, контроля, анализа и хранения письменных обращений заемщиков МФО. Основной сценарий — обращения по реструктуризации микрокредитов, поступающие на `dolg@solva.kz`.

## Почему документы разделены

Проект ведет один разработчик с помощью ИИ-агента. Разделение позволяет Claude:

- не загружать весь проект в контекст;
- работать только с нужной фазой и сервисом;
- не изменять несвязанные компоненты;
- опираться на стабильные API и события;
- выполнять небольшие проверяемые итерации.
